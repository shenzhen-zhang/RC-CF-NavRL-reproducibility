These files contain the archived numerical inputs for the paper's plots and tables. The CPU checks compare recomputed statistics with the applicable reference estimates.

| Reference | Contents |
| --- | --- |
| [`canonical_paired_effects.json`](canonical_paired_effects.json) | Original-cohort paired navigation outcomes |
| [`primary_complete18.csv`](primary_complete18.csv) | Released-checkpoint primary comparisons across 18 evaluation seeds |
| [`scope17_paired_effects_disclosed.json`](scope17_paired_effects_disclosed.json) | Released-checkpoint component comparisons across the common 17 seeds |
| [`mechanism_seed_diagnostics.csv`](mechanism_seed_diagnostics.csv) | Seed-level diagnostics used to render Figure 9 |
| [`deployment_shield_paired_effects.csv`](deployment_shield_paired_effects.csv) | Archived VO effects and intervals used to render Table A4 |
| [`f11_budget_complete18.json`](f11_budget_complete18.json) | Archived finite-episode cost estimates |
