# Plotting code and inputs

- [`environment_setup/`](environment_setup/) renders Figure 3 from a simulator screenshot and obstacle geometry.
- [`flight_case/`](flight_case/) renders the four recorded paths in Figure 5.
- [`teacher_validation/`](teacher_validation/) renders local teacher effects for Figure 8.
- [`data/`](data/) contains scene geometry, trajectory exports, and archived plot inputs. [`reconstruction/`](reconstruction/) contains shared drawing code.

The [build scripts](../build/) render the remaining data figures. See the [figure index](../manuscript/README.md) for the source of each figure.
